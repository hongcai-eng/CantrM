# 合同管理系统升级说明

## 功能变更概述

本次升级将"合同列表"改为"合同管理"，并在导航菜单中增加了层级结构，支持采购合同和销售合同的分类管理。

## 一、新增功能

### 1. 导航菜单升级
- **原菜单**：合同列表
- **新菜单**：合同管理（带下拉菜单）
  - 采购合同
    - 新建合同
    - 合同档案
  - 销售合同
    - 新建合同
    - 合同档案

### 2. 合同类型层级化
- **产品级合同类型**：每个产品可以独立设置合同类型
  - 工程
  - 货物（包含硬件、软件等产品类型）
  - 服务

### 3. 业务类型区分
- 采购合同：用于记录公司的采购业务
- 销售合同：用于记录公司的销售业务

## 二、数据库变更

### 无需新增表或字段
所有功能均基于现有数据库结构实现：

1. **Contract 表**
   - 已有字段 `business_type`：区分采购/销售
   - 已有字段 `contract_type`：保留用于兼容

2. **ContractProduct 表**
   - 已有字段 `contract_type`：产品级合同类型（工程/货物/服务）
   - 已有字段 `product_type`：产品分类（硬件设备/软件/技术服务/技术开发）

### 数据兼容性
- 所有现有数据完全兼容
- 新字段均为可选字段，不影响旧数据显示
- 系统会自动处理空值情况

## 四、使用说明

### 1. 新建采购合同
1. 点击导航栏"合同管理" → "采购合同" → "新建合同"
2. 填写合同基本信息（业务类型自动设为"采购"）
3. 在产品信息区域，为每个产品选择合同类型（工程/货物/服务）
4. 选择产品类型（硬件设备/软件/技术服务/技术开发）
5. 填写其他产品信息（名称、型号、数量、单价等）
6. 保存合同

### 2. 新建销售合同
1. 点击导航栏"合同管理" → "销售合同" → "新建合同"
2. 操作步骤同采购合同

### 3. 查看合同档案
1. 点击导航栏"合同管理" → "采购合同/销售合同" → "合同档案"
2. 可按合同类型、状态、年份等条件筛选
3. 查看统计汇总信息
4. 支持查看、编辑、删除合同

### 4. 原有功能保留
- 点击"合同管理"主菜单仍可查看所有合同（兼容旧功能）
- 所有原有的筛选、统计、导出功能完全保留

## 七、常见问题

### Q1: 旧合同如何显示？
A: 旧合同会根据 `business_type` 字段自动归类到采购或销售合同档案中。

### Q2: 如果产品没有设置合同类型怎么办？
A: 系统会显示"-"，不影响合同的正常使用和统计。

### Q3: 下拉菜单在移动端如何显示？
A: 移动端会自动适配，下拉菜单转为垂直排列。

### Q4: 可以修改已有合同的业务类型吗？
A: 不建议修改已有合同的业务类型。如需修改，请直接编辑数据库。
