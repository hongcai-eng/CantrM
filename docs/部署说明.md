## 数据库迁移

每次有模型字段变更时，在服务器上执行以下脚本：

```bash
cd /opt/CantrM
python3 - <<'EOF'
from app import app, db
from sqlalchemy import text, inspect as sa_inspect

with app.app_context():
    inspector = sa_inspect(db.engine)

    # v3.2：新增试用期字段
    cols = [c['name'] for c in inspector.get_columns('tenant_customer')]
    if 'trial_expires_at' not in cols:
        with db.engine.connect() as conn:
            conn.execute(text('ALTER TABLE tenant_customer ADD COLUMN trial_expires_at DATETIME'))
            conn.commit()
        print('已添加 trial_expires_at 字段')
    else:
        print('trial_expires_at 字段已存在，跳过')

print('迁移完成')
EOF
```

## 常见问题

**python 命令找不到**
```bash
# 系统只有 python3，使用 python3 启动
python3 app.py
```

**pip 安装报 PEP 668 错误**
```bash
pip3 install -r requirements.txt --break-system-packages
```

**SSH 无法登录**
1. 通过阿里云控制台 → 云助手 → 重置实例密码
2. 检查 `/etc/ssh/sshd_config` 中 `PasswordAuthentication` 是否为 `yes`
3. 检查安全组入方向规则是否放行 22 端口

**HTTP 无法访问**
- 检查安全组是否放行 5000 端口（入方向，来源 0.0.0.0/0）
- 确认进程在运行：`ps aux | grep app.py`
