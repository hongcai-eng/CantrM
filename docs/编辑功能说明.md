# 收付款/交付/发票记录编辑功能说明

## 功能概述

为合同详情页面的"收付款记录"、"交付记录"、"发票记录"添加了编辑功能，支持对已创建的记录进行二次编辑，特别是补充上传凭证文件。

## 新增功能

### 1. 编辑收付款记录

**路由**: `/payment/<int:pid>/edit`  
**权限**: 需要"修改"权限

**功能特性**：
- 修改金额、日期、类型、备注等基本信息
- 查看当前已上传的回单文件
- 补充上传新的回单文件（可多选，会追加到已有文件）
- 删除所有回单文件的选项

**使用场景**：
- 之前填写收付款记录时没有上传回单，现在补传
- 需要追加更多的回单文件
- 修改金额、日期等信息

### 2. 编辑交付记录

**路由**: `/delivery/<int:did>/edit`  
**权限**: 需要"修改"权限

**功能特性**：
- 修改交付日期、交付内容、备注等基本信息
- 查看当前已上传的交付记录文件
- 补充上传新的交付记录文件（可多选，会追加到已有文件）
- 删除所有交付文件的选项

**使用场景**：
- 之前填写交付记录时没有上传文件，现在补传
- 需要追加更多的交付记录文件
- 修改交付信息

### 3. 编辑发票记录

**路由**: `/invoice/<int:iid>/edit`  
**权限**: 需要"修改"权限

**功能特性**：
- 修改金额、日期、发票号、发票类型、开具状态、备注等信息
- 发票号重复检测（排除当前记录）
- 查看当前已上传的发票文件
- 补充上传新的发票文件（可多选，会追加到已有文件）
- 删除所有发票文件的选项

**使用场景**：
- 之前填写发票记录时没有上传发票文件，现在补传
- 需要追加更多的发票文件
- 修改发票信息或状态

## 文件上传说明

### 追加模式
- 新上传的文件会**追加**到已有文件列表，不会覆盖原有文件
- 支持多文件上传（可同时选择多个文件）
- 支持格式：PDF、JPG、JPEG、PNG

### 文件管理
- 在编辑页面可以查看所有已上传的文件
- 提供预览和下载功能
- 可以通过"删除所有文件"按钮删除所有已上传的文件
- 删除后可以重新上传

## 技术实现

### 后端路由（app.py）

1. **编辑收付款记录**
   - `@app.route('/payment/<int:pid>/edit', methods=['GET', 'POST'])`
   - GET: 显示编辑表单
   - POST: 处理表单提交，更新数据库，追加新文件

2. **编辑交付记录**
   - `@app.route('/delivery/<int:did>/edit', methods=['GET', 'POST'])`
   - GET: 显示编辑表单
   - POST: 处理表单提交，更新数据库，追加新文件

3. **编辑发票记录**
   - `@app.route('/invoice/<int:iid>/edit', methods=['GET', 'POST'])`
   - GET: 显示编辑表单
   - POST: 处理表单提交，更新数据库，追加新文件
   - 包含发票号重复检测逻辑

### 前端模板

1. **edit_payment.html** - 收付款记录编辑页面
2. **edit_delivery.html** - 交付记录编辑页面
3. **edit_invoice.html** - 发票记录编辑页面
4. **contract_detail.html** - 添加编辑按钮

### 文件处理逻辑

```python
# 追加文件模式
if saved:
    if record.file_field:
        record.file_field = record.file_field + ',' + ','.join(saved)
    else:
        record.file_field = ','.join(saved)
```

## 权限控制

所有编辑功能都需要"修改"权限：
```python
@permission_required('修改')
```

对于只读用户（view_only），编辑按钮不会显示。

## 自动状态更新

编辑收付款记录和发票记录后，会自动触发合同状态更新：
```python
auto_update_contract_status(contract)
```

## 使用流程

### 补充上传凭证文件

1. 进入合同详情页面
2. 找到需要补充文件的记录
3. 点击该记录的"编辑"按钮
4. 在编辑页面的"上传新的XXX文件"区域选择文件
5. 点击"保存修改"
6. 系统会将新文件追加到已有文件列表
7. 返回合同详情页面，可以看到新上传的文件

### 修改记录信息

1. 进入合同详情页面
2. 点击需要修改的记录的"编辑"按钮
3. 修改相关字段（金额、日期、备注等）
4. 点击"保存修改"
5. 返回合同详情页面，修改已生效

## 注意事项

1. **文件追加机制**：新上传的文件会追加到已有文件，不会替换
2. **删除文件**：如需删除文件，使用"删除所有文件"按钮，然后重新上传
3. **发票号唯一性**：编辑发票时，系统会检查发票号是否重复
4. **权限要求**：编辑功能需要"修改"权限
5. **文件格式**：只支持 PDF、JPG、JPEG、PNG 格式
6. **多文件上传**：可以一次选择多个文件同时上传
