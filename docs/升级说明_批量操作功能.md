# 合同列表批量操作功能升级说明

## 📋 升级概述

本次升级为合同列表页面添加了类似邮件的批量操作功能，用户可以通过复选框选择一条或多条合同，然后进行批量查看、编辑或删除操作。

## 🎯 新功能特性

### 1. 批量操作工具栏

```
┌────────────────────────────────────────────────────────────┐
│ ☑ 全选 | 已选择 3 条 | [查看] [编辑] [删除]                │
└────────────────────────────────────────────────────────────┘
```

#### 组件说明

1. **全选复选框**
   - 点击全选/取消全选当前页所有合同
   - 自动同步状态（当所有项都选中时自动勾选）

2. **已选择计数器**
   - 实时显示已选择的合同数量
   - 格式：已选择 X 条

3. **批量操作按钮**
   - **查看按钮**：只允许选择1条记录，跳转到合同详情页
   - **编辑按钮**：只允许选择1条记录，跳转到合同编辑页
   - **删除按钮**：支持选择多条记录，批量删除

### 2. 表格行复选框

- 每行数据前添加复选框
- 点击复选框选择/取消选择该合同
- 选中状态实时更新工具栏按钮和计数器

### 3. 智能按钮状态

| 选择数量 | 查看按钮 | 编辑按钮 | 删除按钮 |
|---------|---------|---------|---------|
| 0条 | 禁用（灰色） | 禁用（灰色） | 禁用（灰色） |
| 1条 | 启用 | 启用 | 启用 |
| 多条 | 启用但提示 | 禁用 | 启用 |

### 4. 操作逻辑

#### 查看操作
- 选择0条：提示"请先选择要查看的合同"
- 选择1条：跳转到合同详情页
- 选择多条：提示"查看操作只支持选择一条记录"

#### 编辑操作
- 选择0条：提示"请先选择要编辑的合同"
- 选择1条：跳转到合同编辑页
- 选择多条：按钮自动禁用

#### 删除操作
- 选择0条：提示"请先选择要删除的合同"
- 选择1条：确认后删除该合同
- 选择多条：确认后批量删除所有选中的合同

### 5. 安全确认

**单条删除确认：**
```
确定删除选中的 1 条合同？此操作不可恢复！
```

**批量删除确认：**
```
确定删除选中的 5 条合同？此操作不可恢复！
```

### 6. 权限控制

- 继承原有权限系统
- 需要"删除"权限才能看到删除按钮
- 批量删除时自动过滤其他租户的合同（多租户隔离）
- 删除成功后显示实际删除的数量

## 📊 技术实现

### 前端实现（JavaScript）

#### 全选/取消全选
```javascript
function toggleSelectAll() {
    const selectAll = document.getElementById('selectAll');
    const checkboxes = document.querySelectorAll('.contract-checkbox');
    checkboxes.forEach(cb => {
        cb.checked = selectAll.checked;
    });
    updateSelectedCount();
}
```

#### 更新选择计数和按钮状态
```javascript
function updateSelectedCount() {
    const checkboxes = document.querySelectorAll('.contract-checkbox:checked');
    const count = checkboxes.length;
    
    // 更新计数显示
    document.getElementById('selectedCount').textContent = `已选择 ${count} 条`;
    
    // 更新按钮状态
    btnView.disabled = count === 0;
    btnEdit.disabled = count !== 1;  // 只允许编辑一条
    btnDelete.disabled = count === 0;
}
```

#### 批量删除
```javascript
function batchDelete() {
    const ids = getSelectedIds();
    
    if (!confirm(confirmMsg)) return;
    
    // 创建表单提交
    const form = document.createElement('form');
    form.method = 'POST';
    form.action = '/contract/batch_delete';
    
    ids.forEach(id => {
        const input = document.createElement('input');
        input.type = 'hidden';
        input.name = 'contract_ids';
        input.value = id;
        form.appendChild(input);
    });
    
    document.body.appendChild(form);
    form.submit();
}
```

### 后端实现（Flask）

#### 批量删除路由
```python
@app.route('/contract/batch_delete', methods=['POST'])
@login_required
@permission_required('删除')
def batch_delete_contracts():
    """批量删除合同"""
    contract_ids = request.form.getlist('contract_ids')
    
    if not contract_ids:
        flash('未选择任何合同', 'warning')
        return redirect(url_for('index'))
    
    # 数据隔离检查
    customer_id = get_current_customer_id()
    
    deleted_count = 0
    for contract_id in contract_ids:
        contract = Contract.query.get(contract_id)
        if contract:
            # 检查权限
            if customer_id is not None and contract.customer_id != customer_id:
                continue  # 跳过其他租户的合同
            
            db.session.delete(contract)
            deleted_count += 1
    
    db.session.commit()
    
    if deleted_count > 0:
        flash(f'成功删除 {deleted_count} 条合同', 'success')
    else:
        flash('没有合同被删除', 'warning')
    
    return redirect(url_for('index'))
```

## 📱 使用指南

### 全选/取消全选
1. 点击工具栏左侧的"全选"复选框
2. 当前页所有合同被选中
3. 再次点击取消全选

### 选择单条合同
1. 点击某一行前面的复选框
2. 该合同被选中
3. 工具栏显示"已选择 1 条"
4. 查看、编辑、删除按钮都可用

### 选择多条合同
1. 点击多行前面的复选框
2. 工具栏显示"已选择 X 条"
3. 查看和删除按钮可用
4. 编辑按钮自动禁用

### 批量查看
1. 选择1条合同
2. 点击"查看"按钮
3. 跳转到合同详情页

### 批量编辑
1. 选择1条合同
2. 点击"编辑"按钮
3. 跳转到合同编辑页

### 批量删除
1. 选择1条或多条合同
2. 点击"删除"按钮
3. 确认删除提示
4. 系统批量删除选中的合同
5. 显示删除成功的数量

## ⚠️ 注意事项

### 1. 权限控制
- 批量操作继承原有权限系统
- 没有"删除"权限的用户看不到删除按钮
- 批量删除时自动过滤无权限的合同

### 2. 多租户隔离
- 批量删除时自动跳过其他租户的合同
- 只删除当前租户有权限的合同
- 删除成功后显示实际删除的数量

### 3. 跨页选择
- 复选框状态不跨页保存
- 切换页面后需要重新选择
- 建议使用筛选功能缩小范围后再批量操作

### 4. 操作限制
- 查看和编辑只支持选择1条记录
- 删除支持选择多条记录
- 选择0条时所有按钮禁用

### 5. 确认提示
- 删除操作有二次确认
- 批量删除显示删除数量
- 取消确认不会执行删除

## 🐛 常见问题

### Q1: 全选后切换页面，复选框状态会保留吗？
A: 不会。复选框状态不跨页保存，切换页面后需要重新选择。

### Q2: 可以一次删除所有合同吗？
A: 可以，但需要分页操作。每页选择全部，然后批量删除。

### Q3: 批量删除后为什么显示的删除数量不对？
A: 批量删除会自动过滤其他租户的合同，只删除当前用户有权限的合同。

### Q4: 编辑按钮为什么一直是灰色？
A: 编辑操作只支持选择1条记录，请确保只选择了1条合同。

### Q5: 点击查看但选了多条怎么办？
A: 系统会提示"查看操作只支持选择一条记录"，请取消多余的选择。
