# 合同列表分页功能升级说明

## 📋 升级概述

本次升级为合同列表页面添加了完整的分页功能，用户可以选择每页显示的数据条数（10/20/50/100条），并支持页面跳转和导航。

## 🎯 新功能特性

### 1. 分页导航条（页尾中央显示）

#### 功能组件
```
┌──────────────────────────────────────────────────────────────────┐
│                                                                  │
│  每页显示：[10条▼]   [首页] [上一页] 第1/5页(共48条) [下一页] [末页]   跳转到：[__] [GO]  │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

#### 组件说明

1. **每页显示选择器**
   - 下拉选择框：10条 / 20条 / 50条 / 100条
   - 切换时自动回到第1页
   - 保留所有筛选条件

2. **页面导航按钮**
   - **首页**：跳转到第1页
   - **上一页**：跳转到前一页
   - **下一页**：跳转到下一页
   - **末页**：跳转到最后一页
   - 首页和上一页在第1页时禁用（灰色显示）
   - 末页和下一页在最后一页时禁用（灰色显示）

3. **页码信息显示**
   - 显示格式：第 X / Y 页 （共 Z 条）
   - X：当前页码
   - Y：总页数
   - Z：总记录数

4. **页面跳转输入框**
   - 输入页码直接跳转
   - 点击 GO 按钮跳转
   - 支持回车键跳转
   - 输入范围验证（1 到最大页数）

### 2. 应用范围

分页功能已应用到以下页面：

1. ✅ **合同列表页面** (`/` 或 `/contracts`)
   - 租户用户的主界面
   - 显示所有合同（支持筛选）

2. ✅ **采购合同档案** (`/contract/archive/采购`)
   - 采购合同专用列表页

3. ✅ **销售合同档案** (`/contract/archive/销售`)
   - 销售合同专用列表页

### 3. 交互特性

- ✅ 页码和每页条数保持在URL参数中
- ✅ 切换每页条数时自动回到第1页
- ✅ 筛选条件在翻页时自动保留
- ✅ 导出Excel时不受分页影响（导出所有筛选结果）
- ✅ 统计数据始终显示所有数据的统计（不受分页影响）
- ✅ 响应式设计，移动端自动调整布局

### 4. 样式设计

- **位置**：表格下方，页尾中央
- **布局**：水平居中，三组控件（每页选择 | 导航按钮 | 跳转输入）
- **间距**：20px gap，清晰分隔
- **按钮样式**：继承系统按钮样式
- **禁用状态**：半透明（opacity: 0.5），禁用鼠标点击

## 📊 技术实现

### 后端逻辑（app.py）

#### index 路由
```python
# 获取分页参数
page = request.args.get('page', 1, type=int)
per_page = request.args.get('per_page', 10, type=int)

# 计算总页数
total_contracts = len(contracts)
total_pages = (total_contracts + per_page - 1) // per_page

# 分页切片
start_idx = (page - 1) * per_page
end_idx = start_idx + per_page
contracts_page = contracts[start_idx:end_idx]

# 传递分页信息到模板
return render_template('index.html',
                      contracts=contracts_page,
                      page=page,
                      per_page=per_page,
                      total_pages=total_pages,
                      total_contracts=total_contracts,
                      ...)
```

#### contract_archive 路由
- 完全相同的分页逻辑
- 支持采购/销售合同独立分页

### 前端逻辑（模板）

#### URL参数处理
```jinja2
{% if page > 1 %}
<a href="?{{ request.query_string.decode() | replace('page=' ~ page, 'page=1') }}">首页</a>
{% endif %}
```

#### JavaScript 函数
```javascript
// 切换每页显示数量
function changePerPage(perPage) {
    const url = new URL(window.location.href);
    url.searchParams.set('per_page', perPage);
    url.searchParams.set('page', '1');
    window.location.href = url.toString();
}

// 跳转到指定页码
function gotoPage() {
    const pageNum = document.getElementById('gotoPage').value;
    const maxPage = {{ total_pages }};
    
    if (pageNum < 1 || pageNum > maxPage) {
        alert('请输入有效的页码（1-' + maxPage + '）');
        return;
    }
    
    const url = new URL(window.location.href);
    url.searchParams.set('page', pageNum);
    window.location.href = url.toString();
}
```

## 📱 使用指南

1. 在页尾找到"每页显示"下拉框
2. 选择 10条 / 20条 / 50条 / 100条

2. 点击"上一页"：前进一页

1. 在"跳转到"输入框输入页码
2. 点击"GO"按钮或按回车键
3. 系统跳转到指定页面

### 筛选和分页
1. 使用筛选条件筛选合同
2. 点击"筛选"按钮
3. 筛选结果自动分页显示
4. 翻页时筛选条件自动保留

## ⚠️ 注意事项

### 1. 统计数据
- 页面顶部的统计数据（合同数量、总金额等）始终显示**所有筛选结果的统计**
- 不受分页影响

### 2. 导出功能
- 导出Excel功能导出**所有筛选结果**
- 不受分页限制

### 3. URL参数
- 分页参数保存在URL中：`?page=2&per_page=20`
- 可以直接收藏或分享带分页的URL

### 4. 性能优化
- 分页在Python层面进行切片
- 大数据量时建议选择较小的每页条数
- 未来可优化为数据库级别的分页查询

### 5. 筛选条件保留
- 所有筛选条件在翻页时自动保留
- 切换每页条数时也会保留筛选条件

## 🐛 常见问题

### Q1: 翻页后筛选条件丢失？
A: 不会丢失。所有筛选条件都保存在URL参数中，翻页时自动保留。

### Q2: 统计数据只显示当前页？
A: 不是。统计数据始终显示所有筛选结果的统计，不受分页影响。

### Q3: 导出Excel只导出当前页？
A: 不是。导出功能导出所有筛选结果，不受分页限制。

### Q4: 可以直接跳转到某一页吗？
A: 可以。使用"跳转到"输入框输入页码，点击GO或按回车键。

### Q5: 每页最多可以显示多少条？
A: 目前提供 10/20/50/100 四个选项，可根据需要调整。

### Q6: 移动端分页如何显示？
A: 移动端自动调整布局，控件垂直排列以适应小屏幕。
