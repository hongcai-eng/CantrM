# 修改记录补充5 - 可选显示已完结合同 2026.07.13

## 问题描述

梁靓为项目部经理，应该能看到付伟龙和毕少鹏的所有项目，但目前只能看到付伟龙的9个合同，看不到毕少鹏的2个合同。

## 问题诊断

### 情况分析
- 付伟龙的合同：组织18（付伟龙项目），9条**进行中**合同 ✓ 梁靓能看到
- 毕少鹏的合同：组织19（王薇项目），2条**已完结**合同 ✗ 梁靓看不到

### 原因
数据权限规则中的设计：
```python
# 本组织合同：只显示"进行中"的合同（已完结的不随组织显示）
Contract.status != '已完结'
```

**设计初衷**：防止历史数据太多，已完结合同只有原负责人/创建人能看到，不出现在组织列表中。

**实际需求**：上级管理者需要看到下级的所有项目，包括已完结的，用于统计、查询和管理。

## 解决方案

采用**折中方案**：
- 默认不显示已完结合同（保持页面简洁）
- 在筛选条件中增加"包含已完结合同"复选框
- 用户勾选后，显示所有合同（进行中+已完结）

## 实现细节

### 1. 后端改动

#### 修改数据权限函数签名
```python
def get_user_accessible_contract_ids(user_id, customer_id, include_finished=False):
    """
    新增参数：
        include_finished: 是否包含已完结合同（默认False）
    """
```

#### 修改"本组织合同"查询逻辑
**修改前**：
```python
org_contracts = Contract.query.filter(
    Contract.organization_id.in_(expanded_org_ids),
    Contract.status != '已完结'  # 硬编码过滤
).all()
```

**修改后**：
```python
query = Contract.query.filter(
    Contract.organization_id.in_(expanded_org_ids)
)

# 根据参数动态决定是否过滤已完结
if not include_finished:
    query = query.filter(Contract.status != '已完结')

org_contracts = query.all()
```

#### 修改路由读取参数
在 `index()` 和 `contract_archive()` 路由中：
```python
# 读取"包含已完结合同"选项
include_finished = request.args.get('include_finished') == '1'
accessible_ids = get_user_accessible_contract_ids(user_id, customer_id, include_finished)
```

### 2. 前端改动

在筛选表单末尾增加复选框（index.html 和 contract_archive.html）：
```html
<div class="form-row">
    <div class="form-group">
        <label style="display:block;margin-bottom:5px;">
            <input type="checkbox" name="include_finished" value="1" 
                   {% if request.args.get('include_finished') %}checked{% endif %}>
            包含已完结合同（默认只显示进行中的合同）
        </label>
    </div>
</div>
```

## 用户体验

### 使用流程
1. 用户登录后，默认看到进行中的合同（简洁，日常工作）
2. 需要查询历史或统计时，勾选"包含已完结合同"
3. 提交筛选，查看所有合同（进行中+已完结）
4. 点击"清除"按钮，恢复默认（不含已完结）

### 适用场景
- ✅ 上级管理者查看下级所有项目（含历史）
- ✅ 项目统计、年度总结
- ✅ 查找历史合同资料
- ✅ 保持日常列表简洁（默认不显示已完结）

## 业务价值

1. **平衡了管理需求和日常使用**：默认简洁，按需查看全部
2. **解决了组织层级权限的遗留问题**：上级能看到下级的已完结项目
3. **提供了灵活的查询方式**：用户自主控制显示范围
