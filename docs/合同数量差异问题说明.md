# 合同数量差异问题说明

## 🔍 问题根源

您提到"本岗位下的合同目前有11个，不同的员工现在看到的合同数额不对"。

经过诊断发现：

### 实际情况
- **合同总数**: 117个
- **已分配组织的合同**: 11个 ✅
- **未分配组织的合同**: 106个 ❌

### 问题分析
106个合同的 `organization_id` 字段为 `None`，没有分配到任何组织。

**当用户岗位的数据权限为"本组织合同"时**：
- 系统会查询 `Contract.organization_id = 用户的组织ID` 的合同
- 如果合同没有 `organization_id`，用户无法看到
- 不同组织的用户看到的合同数量不同

**组织合同分布**：
- 组织10: 5个合同
- 组织8: 2个合同
- 组织6: 4个合同
- **其他组织**: 0个合同（所以看不到）

---

## ✅ 解决方案

### 方案1：批量分配合同到组织（推荐）

使用脚本 `assign_contracts_to_organizations.py`：

```bash
python assign_contracts_to_organizations.py
```

**提供5种分配方式**：
1. **全部分配到同一个组织**（适合所有合同属于同一部门）
2. **根据项目负责人自动分配**（推荐）
3. **根据创建人自动分配**
4. **手动逐个分配**（适合少量合同）
5. **导出Excel后手动分配**

### 方案2：在合同管理界面手动分配

1. 进入"合同管理"
2. 编辑每个合同
3. 在"所属组织/部门"下拉框中选择组织
4. 保存

### 方案3：使用SQL批量分配

```sql
-- 示例：将所有未分配的合同分配到管理部（假设ID为1）
UPDATE contract 
SET organization_id = 1 
WHERE organization_id IS NULL;
```

## 📋 推荐操作流程

### 步骤1：确定分配策略
- 如果所有合同属于同一部门 → 使用方案1-选项1
- 如果合同应该跟项目负责人 → 使用方案1-选项2
- 如果需要手动决定 → 使用方案1-选项5（导出Excel）

### 步骤2：执行分配
```bash
python assign_contracts_to_organizations.py
```

### 步骤3：验证结果
```python
python -c "
from app import app, db
from models import Contract

with app.app_context():
    unassigned = Contract.query.filter_by(organization_id=None).count()
    print(f'未分配组织的合同: {unassigned} 个')
    
    # 按组织统计
    from sqlalchemy import func
    stats = db.session.query(
        Contract.organization_id, 
        func.count(Contract.id)
    ).group_by(Contract.organization_id).all()
    
    print('\\n各组织的合同数:')
    for org_id, count in stats:
        if org_id:
            print(f'  组织ID {org_id}: {count} 个')
"
```

### 步骤4：用户刷新页面
分配完成后，让用户刷新页面，应该能看到正确数量的合同。

## 🎯 为什么会出现这个问题？

### 原因
1. 合同创建时，"所属组织/部门"字段为**可选**
2. 历史合同可能没有填写组织
3. 系统升级前创建的合同没有组织字段

### 预防措施
**已在系统中添加的功能**：
- 合同表单中有"所属组织/部门"选择框
- 创建合同时建议选择组织
- 但不是必填（为了兼容性）

**建议**：
- 新建合同时务必选择"所属组织/部门"
- 定期检查未分配组织的合同
- 及时分配到相应组织

## 📊 不同数据权限的影响

| 数据权限 | 能看到的合同 |
|---------|-------------|
| 全部合同 | 所有合同（不受organization_id影响） |
| 本组织合同 | 只能看到 `organization_id = 用户组织ID` 的合同 ❌ |
| 仅自己创建 | 只能看到自己创建和负责的合同 |
| 自定义 | 只能看到被授权的合同 |

**所以**："本组织合同"权限的用户受 `organization_id` 字段影响最大。

---

## 💡 临时解决方案

如果暂时不想分配组织，可以：

**修改岗位数据权限**：
1. 进入"岗位管理"
2. 编辑该岗位
3. 将"数据权限范围"从"本组织合同"改为"全部合同"
4. 保存
5. 用户刷新页面后可以看到所有合同

**缺点**：失去了组织数据隔离的作用。

---

## 🔧 快速修复命令

如果确定所有合同都属于"管理部"（假设ID为1）：

```bash
python -c "
from app import app, db
from models import Contract

with app.app_context():
    result = Contract.query.filter_by(organization_id=None).update({'organization_id': 1})
    db.session.commit()
    print(f'已将 {result} 个合同分配到组织ID=1')
"
```
