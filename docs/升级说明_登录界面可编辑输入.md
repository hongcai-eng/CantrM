# 登录界面可编辑输入框升级说明

## 📋 升级概述

本次升级将登录界面的"公司"和"切换账号"下拉选择框改为支持手动编辑输入和下拉选择的组合框（Combobox），提升用户体验和灵活性。

## 🎯 新功能特性

### 1. 公司选择框升级

#### 原功能
- 纯下拉选择框（`<select>`）
- 只能从列表中选择
- 无法手动输入

#### 新功能
- **可编辑的组合框**（`<input>` + `<datalist>`）
- 支持手动输入公司名称
- 支持从下拉列表中选择
- 输入时自动匹配并提示
- 自动更新品牌信息

#### 使用场景
1. **快速输入**：直接输入公司名称，无需从长列表中查找
2. **模糊搜索**：输入部分公司名，浏览器自动筛选匹配项
3. **新公司支持**：可以输入尚未在列表中的公司名（虽然登录可能失败，但不会阻止输入）

### 2. 切换账号选择框升级

#### 原功能
- 纯下拉选择框（`<select>`）
- 只能从已保存的账号列表中选择

#### 新功能
- **可编辑的组合框**（`<input>` + `<datalist>`）
- 支持手动输入用户名
- 支持从已保存账号列表中选择
- 输入时自动匹配已保存账号
- 选中后自动填充用户名和密码

#### 使用场景
1. **快速输入**：直接输入用户名，无需从列表中选择
2. **账号联想**：输入时自动显示匹配的已保存账号
3. **灵活切换**：既可以选择已保存账号，也可以输入新账号

### 3. 智能交互

#### 自动品牌更新
- 输入公司名称时实时更新品牌logo和系统标题
- 输入用户名失焦时自动获取品牌信息
- 选择已保存账号时自动更新品牌

#### 数据同步
- 公司名称自动匹配 customer_id
- 用户名自动关联公司信息
- 表单提交时自动处理数据

#### JavaScript 逻辑

**公司输入框监听**
```javascript
document.getElementById('companyInput').addEventListener('input', function() {
    var companyName = this.value.trim();
    
    // 查找匹配的公司ID
    var options = document.querySelectorAll('#companyList option');
    var foundId = '';
    for (var i = 0; i < options.length; i++) {
        if (options[i].value === companyName) {
            foundId = options[i].getAttribute('data-id') || '';
            break;
        }
    }
    
    // 更新隐藏字段
    document.getElementById('customerIdHidden').value = foundId;
    
    // 更新品牌显示
    if (companyName && foundId) {
        updateBranding(companyName, '');
    }
});
```

**账号输入框监听**
```javascript
document.getElementById('accountInput').addEventListener('input', function() {
    var username = this.value.trim();
    
    // 查找匹配的已保存账号
    var accounts = JSON.parse(localStorage.getItem('savedAccounts') || '[]');
    var account = accounts.find(function(a) { return a.username === username; });
    
    if (account) {
        document.getElementById('usernameInput').value = account.username;
        document.getElementById('passwordInput').value = account.password;
        fetchBranding(account.username);
    }
});
```

## 📱 使用指南

### 公司选择框使用

#### 方式一：手动输入
1. 点击"公司"输入框
2. 直接输入公司名称（如"北京科技有限公司"）
3. 系统自动匹配并更新品牌
4. 如果匹配成功，品牌logo和名称自动显示

#### 方式二：下拉选择
1. 点击"公司"输入框
2. 浏览器自动显示所有可用公司列表
3. 点击选择目标公司
4. 系统自动填充并更新品牌

#### 方式三：搜索选择
1. 点击"公司"输入框
2. 输入公司名称的部分字符（如"北京"）
3. 浏览器自动筛选匹配的公司
4. 从筛选结果中选择目标公司

### 切换账号使用

#### 方式一：手动输入
1. 点击"切换账号"输入框
2. 直接输入用户名
3. 如果是已保存账号，自动填充密码

2. 浏览器显示所有已保存的账号

4. 用户名和密码自动填充

## ⚠️ 注意事项

### 1. 浏览器兼容性
- `<datalist>` 是 HTML5 标准，主流浏览器均支持
- IE 10+ 支持
- 移动端浏览器支持良好

### 2. 数据匹配
- 公司名称必须完全匹配才能自动获取 customer_id
- 大小写敏感
- 建议从下拉列表中选择以确保准确

### 3. 输入提示
- 输入时浏览器会自动显示匹配项
- 下拉列表的样式由浏览器控制，无法自定义
- 不同浏览器的显示效果可能略有差异

### 4. 向后兼容
- 原有通过 customer_id 登录的方式仍然支持
- API接口不受影响
- 已保存的账号信息完全兼容

### 5. 安全性
- 客户端验证仅用于用户体验
- 服务器端仍然进行完整的身份验证
- 无效的公司名称会导致登录失败

## 🐛 常见问题

### Q1: 输入公司名称后品牌不更新？
A: 检查公司名称是否完全匹配列表中的名称，建议从下拉列表中选择。

### Q2: 下拉列表不显示？
A: 确保浏览器支持 HTML5 datalist，或者更新浏览器版本。

### Q3: 输入公司名称可以登录其他公司吗？
A: 不能。即使输入其他公司名称，服务器端仍会验证用户名和密码是否属于该公司。

### Q4: 已保存的账号在切换账号中看不到？
A: 检查浏览器 localStorage，确认账号已保存。可以重新勾选"记住此账号"并登录一次。

### Q5: 可以输入不存在的公司名称吗？
A: 可以输入，但登录会失败。系统会提示"用户名或密码错误"。
