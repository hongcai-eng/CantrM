# 合同组织分配管理功能说明

## ✅ 新增功能

  最终的"本组织合同"权限逻辑

  已完结合同的可见范围现在包括三类人：

  ┌───────────────────────┬───────────────────────────────────────────────────────────┐
  │       可见对象        │                           说明                            │
  ├───────────────────────┼───────────────────────────────────────────────────────────┤
  │ 原合同负责人/创建人   │ 通过 created_by 和 project_staff 识别，人员调动后仍能看到 │
  ├───────────────────────┼───────────────────────────────────────────────────────────┤
  │ 岗位/组织被显式授权者 │ 通过 PositionContractPermission（授权合同）识别           │
  ├───────────────────────┼───────────────────────────────────────────────────────────┤
  │ ~~普通组织成员~~      │ ❌ 已完结合同不随组织显示                                 │
  └───────────────────────┴───────────────────────────────────────────────────────────┘

  完整可见合同计算公式

  用户可见合同 = 本组织"进行中"合同
              + 自己负责/创建的所有合同（含已完结）
              + 岗位被显式授权的合同（含已完结）

  效果说明

  - 进行中的合同：本组织成员正常可见
  - 已完结的合同：只有原负责人 + 被岗位授权者可见，不会因人员调动显示给新部门的其他成员
  - 原负责人：即使调到新部门，仍能一直看到自己的历史已完结合同

已为您添加了一个可视化的**合同组织分配管理**入口，方便批量管理合同的组织归属。

---

## 📍 访问入口

**位置**：租户管理员登录后 → 顶部菜单栏 → **"合同组织分配"**

**权限**：仅超级管理员可访问

---

## 🎯 功能特性

### 1. 统计概览
- 显示各组织的合同数量和占比
- 高亮显示未分配组织的合同
- 实时统计合同总数

### 2. 批量分配方式（4种）

#### 方式1：全部分配到同一组织
- **适用场景**：所有合同属于同一部门
- **操作**：选择目标组织 → 点击"执行分配"
- **效果**：一键将所有合同分配到选定组织

#### 方式2：根据项目负责人自动分配 ⭐推荐
- **适用场景**：合同已填写项目负责人
- **逻辑**：自动根据项目负责人的组织分配合同
- **优点**：智能分配，符合实际业务逻辑

#### 方式3：根据创建人自动分配
- **适用场景**：合同创建人归属明确
- **逻辑**：自动根据合同创建人的组织分配
- **优点**：基于创建人归属分配

#### 方式4：清除所有分配
- **适用场景**：需要重新开始分配
- **效果**：清除所有合同的组织归属
- **警告**：操作不可恢复，需要确认

### 3. 单个合同分配
- 显示所有未分配组织的合同列表
- 支持逐个选择组织进行分配
- 显示合同编号、项目名称、项目负责人、创建人

---

## 📋 使用流程

### 推荐操作步骤

1. **访问管理页面**
   - 登录超级管理员账号
   - 点击顶部菜单"合同组织分配"

2. **查看统计信息**
   - 查看各组织的合同分布
   - 确认有多少合同未分配

3. **选择分配方式**
   - 如果合同有项目负责人：选择"根据项目负责人自动分配"
   - 如果想统一管理：选择"全部分配到同一组织"
   - 如果需要手动控制：使用单个合同分配

4. **执行分配**
   - 点击相应按钮执行分配
   - 系统会提示确认
   - 完成后显示分配数量

5. **通知用户刷新**
   - 分配完成后，通知用户刷新页面
   - 用户即可看到正确的组织合同

## 🔧 如需调整分配

如果当前分配不合理，可以：

1. **重新分配到管理部**：
   - 进入"合同组织分配"页面
   - 选择"全部分配到同一组织"
   - 选择"管理部"
   - 点击"执行分配"

2. **清除后重新分配**：
   - 点击"清除所有分配"
   - 再选择合适的分配方式重新分配

---

## 📌 注意事项

1. **数据权限影响**
   - 岗位数据权限为"本组织合同"的用户只能看到本组织的合同
   - 合同必须分配到组织，用户才能看到

2. **项目负责人匹配**
   - 自动分配时，系统会匹配"项目负责人"字段和用户名
   - 如果匹配不上，该合同不会被自动分配

3. **操作可逆**
   - 除了"清除所有分配"外，其他操作都可以重复执行
   - 可以随时调整合同的组织归属
