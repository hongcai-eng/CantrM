# 合同管理系统升级说明 - 混合菜单版

## 📋 升级概述

本次升级实现了**横向菜单+左侧弹出面板**的混合布局模式，将"合同列表"改为"合同管理"，并在点击后从左侧弹出详细的四级菜单结构。

## 🎯 新功能特性

### 1. 菜单交互模式（桌面端）


### 2. 布局特点

#### 桌面端
- **顶部导航栏**：横向菜单，保留原有布局习惯
- **合同管理菜单**：点击后从左侧弹出深色面板（280px宽）
- **背景遮罩**：半透明黑色遮罩，突出侧边栏
- **内容区域**：全宽自适应，白色背景
- **平滑动画**：侧边栏滑入滑出，视觉流畅

#### 移动端
- 顶部显示汉堡菜单按钮☰
- 点击按钮弹出侧边栏（与桌面端相同）
- 内容区全屏显示

### 3. 交互功能

- ✅ 点击菜单项展开/收起子菜单
- ✅ 箭头指示展开状态（▶未展开 ▼已展开）
- ✅ 展开一个菜单时自动关闭同级其他菜单
- ✅ 页面加载时自动展开当前页面路径
- ✅ 当前页面菜单项高亮显示
- ✅ 鼠标悬停效果

### 4. 合同类型说明

点击菜单中的合同类型后：
- **工程合同**：用于工程类项目
- **货物合同**：包含硬件设备、软件等产品类合同
- **服务合同**：技术服务、技术开发等服务类合同

每种类型会通过URL参数传递到新建合同页面：
- `/contract/new/采购?contract_type=工程`
- `/contract/new/采购?contract_type=货物`
- `/contract/new/采购?contract_type=服务`

## 📱 使用指南

### 新建采购合同（工程类）
1. 点击"合同管理" → 展开菜单
2. 点击"采购合同" → 展开菜单
3. 点击"新建合同" → 展开菜单
4. 点击"工程" → 进入新建页面
5. 填写合同信息，业务类型自动设为"采购"
6. 在产品信息中，合同类型可设置为"工程"
7. 保存合同

### 新建销售合同（货物类）
1. 点击"合同管理" → "销售合同" → "新建合同" → "货物（硬件、软件）"
2. 填写合同信息，业务类型自动设为"销售"
3. 在产品信息中，合同类型可设置为"货物"
4. 产品类型选择"硬件设备"或"软件"
5. 保存合同

### 查看合同档案
1. 点击"合同管理" → "采购合同"/"销售合同" → "合同档案"
2. 使用筛选条件查找合同
3. 查看统计数据
4. 可以查看、编辑、删除合同

## 🐛 常见问题

### Q1: 菜单无法展开？
A: 检查浏览器控制台是否有JavaScript错误，确保base.html中的JavaScript代码完整。

### Q2: 样式显示异常？
A: 清除浏览器缓存，强制刷新页面（Ctrl+F5）。

### Q3: 移动端菜单无法呼出？
A: 确保汉堡菜单按钮的JavaScript事件绑定正常。

### Q4: 点击合同类型后页面空白？
A: 检查app.py中的路由是否正确，确认 `new_contract_with_type` 函数存在。

### Q5: 旧数据合同类型显示"-"？
A: 正常现象，旧合同未设置合同类型字段，不影响使用。可手动编辑补充。
