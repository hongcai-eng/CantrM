# 客户管理系统升级说明

## 📋 升级概述

本次升级为"客户管理"功能实现了与"合同管理"类似的结构，支持采购客户和销售客户的分类管理。

## 🎯 新功能特性

### 1. 客户管理菜单结构

#### 顶部横向菜单
```
Logo - 合同管理系统 | 合同管理 | 客户管理 | 产品管理 | 统计分析 | ... | 用户信息 | 退出
```

#### 点击"客户管理"后左侧弹出菜单面板
```
左侧弹出面板（280px宽）：

采购客户管理
├── 新建客户
└── 客户档案

销售客户管理
├── 新建客户
└── 客户档案
```

### 2. 功能说明

#### 采购客户管理
- **新建客户**：创建新的采购客户，业务类型自动设为"采购"
- **客户档案**：查看所有采购客户列表，支持筛选和编辑

#### 销售客户管理
- **新建客户**：创建新的销售客户，业务类型自动设为"销售"
- **客户档案**：查看所有销售客户列表，支持筛选和编辑

### 3. 交互特性

- ✅ 点击"客户管理"从左侧弹出菜单面板
- ✅ 半透明背景遮罩，聚焦侧边栏
- ✅ 点击遮罩层或链接后自动关闭
- ✅ 支持与"合同管理"菜单独立切换
- ✅ 菜单项打开时高亮显示
- ✅ 平滑动画过渡

### 4. 数据隔离

- 按业务类型（采购/销售）区分客户
- 保持多租户数据隔离
- 支持按客户名称、省份筛选

## 📊 数据库变更

### 新增字段

| 表名 | 字段名 | 类型 | 说明 | 默认值 |
|------|--------|------|------|--------|
| Customer | business_type | VARCHAR(20) | 业务类型（采购/销售） | '销售' |

### 迁移说明

字段 `business_type` 已添加到 `Customer` 模型中，Flask会在应用启动时自动创建。如需手动迁移，可运行：

```bash
python migrate_customer_business_type.py
```

### 数据兼容性

- ✅ 现有客户数据完全兼容
- ✅ 默认业务类型为"销售"
- ✅ 旧客户自动归类为销售客户
- ✅ 可手动修改客户的业务类型

## 🐛 常见问题

### Q1: 旧客户显示在哪里？
A: 旧客户的 `business_type` 默认为"销售"，会显示在"销售客户档案"中。

### Q2: 可以修改客户的业务类型吗？
A: 目前界面不支持修改。如需修改，可通过数据库直接更新：
```sql
UPDATE customer SET business_type = '采购' WHERE id = 客户ID;
```

### Q3: 客户管理和合同管理菜单会冲突吗？
A: 不会。JavaScript已优化，支持独立切换不同的侧边栏菜单。

### Q4: 点击菜单没反应？
A: 清除浏览器缓存，强制刷新页面（Ctrl+F5）。

### Q5: 数据库迁移失败？
A: Flask会在启动时自动创建字段，通常无需手动迁移。如果遇到问题，检查数据库连接和权限。
