## ⚠️ 常见问题

### Q1: 数据库迁移失败怎么办？

**错误信息：**
```
sqlalchemy.exc.OperationalError: no such column: customer.business_type
```

**解决方案：**
```bash
# 1. 停止应用
pkill gunicorn

# 2. 运行迁移脚本
python migrate_simple.py

# 3. 验证字段已添加
python -c "import sqlite3; conn = sqlite3.connect('instance/contracts.db'); cursor = conn.cursor(); cursor.execute('PRAGMA table_info(customer)'); print([c[1] for c in cursor.fetchall()])"

# 4. 重启应用
gunicorn -c gunicorn_config.py app:app
```

### Q2: 菜单点击没反应？

**解决方案：**
1. 清除浏览器缓存（Ctrl + F5）
2. 检查浏览器控制台（F12）是否有 JavaScript 错误
3. 确认 base.html 文件完整更新

### Q3: 旧客户找不到了？

**说明：**
旧客户的 `business_type` 默认为"销售"，在"销售客户档案"中查看。

### Q4: 分页导航条不显示？

**检查：**
1. 确认 index.html 和 contract_archive.html 已更新
2. 确认 app.py 中的路由已添加分页参数
3. 清除浏览器缓存

### Q5: 部署后仍然报错？

**排查步骤：**
```bash
# 1. 查看应用日志
tail -f gunicorn.log

# 2. 检查文件权限
ls -l instance/contracts.db

# 3. 验证Python环境
which python
python --version

# 4. 检查依赖
pip list | grep -i flask
```
