# 租户独立系统配置

## 问题
一个租户修改了系统名称后，其他租户的系统名称也跟着改变。

## 解决方案
每个租户拥有独立的系统配置（系统名称、公司名称、公司图标），互不影响。

## 实现逻辑

### 1. 数据存储
- **租户配置**：存储在 `tenant_customer` 表的 `system_name`、`company_name`、`logo_file` 字段
- **全局配置**：存储在 `SysConfig` 表（仅供 superadmin 使用）

### 2. 配置保存
- **superadmin**：保存到全局 `SysConfig` 表
- **租户超管**：保存到当前租户的 `tenant_customer` 记录

### 3. 配置读取（context_processor）
- **superadmin**：读取全局 `SysConfig`
- **租户用户**：读取所属租户的配置，优先级：租户配置 > 全局配置

### 4. 图标文件命名
- **全局**：`company_logo.{ext}`
- **租户**：`tenant_{tenant_id}_logo.{ext}`

## 修改内容

### 数据库
新增字段：`tenant_customer.system_name VARCHAR(200)`

### 代码文件
1. **models.py**：在 `TenantCustomer` 类中添加 `system_name` 字段
2. **app.py**：
   - 修改 `sysconfig()` 路由，区分 superadmin 和租户超管的保存/读取逻辑
   - 修改 `inject_globals()` context_processor，优先读取租户的 `system_name`

## 效果
- 每个租户可以独立配置自己的系统名称、公司名称、公司图标
- 租户之间配置互不影响
- superadmin 的配置独立，显示"系统总后台"标识
