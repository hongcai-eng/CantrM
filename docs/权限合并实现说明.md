  岗位分配流程

  1. 进入"岗位管理"
  2. 找到岗位，点击"分配用户"
  3. 选择用户和组织
  4. ✅ 系统自动：
    - 创建岗位分配
    - 同步组织关联

  1. 编辑合同
  2. 在"所属组织/部门"中选择组织
  3. 保存
  4. ✅ 该组织的员工立即可以看到这个合同

    🔑 系统工作原理

  组织调动时的同步更新

  当管理员执行"调入"操作时，系统自动完成以下同步：

  1. 更新用户主组织
    - User.organization_id = 新组织ID
  2. 更新组织关联表
    - 取消所有 UserOrganization.is_primary
    - 设置新组织的 is_primary = True
  3. 更新所有岗位的组织归属 ⭐ 新增
    - 遍历用户的所有 UserPosition
    - 将 organization_id 更新为新组织
  4. 数据权限自动生效
    - 基于主组织计算可访问合同
    - 用户立即只能看到新组织的数据
