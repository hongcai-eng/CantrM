# 修改记录补充3 - 岗位分配智能提示 2026.07.13

## 问题描述

用户反馈：租户用户总管理员在"岗位管理"中将梁靓分配到"项目部总经理"岗位后，梁靓登录后看不到任何合同。

## 问题诊断

### 具体情况
- 梁靓（李丹，user_id=11）被分配到"项目部总经理"岗位
- 岗位数据范围：`org`（本组织合同）
- 所属组织：组织17（项目部）
- **组织17下合同数：0条**

### 根本原因
当岗位的数据范围是"本组织合同"时，用户只能看到其所属组织下的合同。如果该组织下没有合同，或合同都已完结，用户就看不到任何数据。

权限计算逻辑（`get_user_accessible_contract_ids()`）：
- 数据范围 = `org` → 查询该组织下"进行中"的合同
- 组织17下合同数 = 0
- 用户也不是任何合同的负责人/创建人
- 结果：返回空列表 `[]`，看不到任何合同

### 租户3合同分布
```
组织18（付伟龙项目）: 9条
组织19（王薇项目）: 2条
组织17（项目部）: 0条
```

## 解决方案

在分配岗位后，智能检查用户能访问的合同数量，并给出针对性提示：

### 场景1：组织下没有合同（如组织17）
**提示**：
```
⚠️ 已为用户"梁靓"分配岗位"项目部总经理"（数据范围：本组织）。
但组织"项目部"下目前没有合同，该用户暂时无法看到任何合同。
建议：前往"合同组织分配"页面，将合同分配给"项目部"组织。
```

### 场景2：组织有合同但用户无法访问
**提示**：
```
⚠️ 已为用户"XXX"分配岗位"XXX"。
组织"XXX"有X条合同，但该用户当前无法访问（可能合同都已完结，或用户未被显式授权）。
```

### 场景3：正常情况（用户能访问合同）
**提示**：
```
✓ 已为用户"XXX"分配岗位"XXX"，该用户可访问 X 条合同。
```

### 场景4：数据范围为"全部"
**提示**：
```
✓ 已为用户"XXX"分配岗位"XXX"，该用户可访问全部合同。
```

## 改动内容

### 涉及文件
- `app.py` - `assign_user_to_position()` 函数

### 具体修改
在 `db.session.commit()` 后，增加智能提示逻辑：

1. 调用 `get_user_accessible_contract_ids()` 计算用户能访问的合同
2. 根据返回值判断：
   - `None`（全部合同）→ 成功提示
   - `[]`（空列表）→ 警告提示，并给出具体原因和解决建议
   - 非空列表 → 成功提示，显示合同数量
3. 对于"本组织"数据范围且无合同的情况，明确提示需要前往"合同组织分配"

## 用户体验改进

### 修改前
管理员分配岗位后，没有任何提示。用户登录后看不到合同，管理员不知道原因，用户也不知道为什么。

### 修改后
管理员分配岗位时立即获得反馈：
1. **清晰的状态反馈**：成功/警告，用户能访问多少合同
2. **明确的原因说明**：为什么看不到合同（组织下没有合同）
3. **可操作的建议**：前往"合同组织分配"页面分配合同

## 后续操作指引

当管理员看到"组织下没有合同"的警告后，应：

1. 前往"合同组织分配"页面（总管理员菜单可见）
2. 点击该组织的"查看合同列表"
3. 使用批量分配工具，将相关合同分配给该组织

或者：

1. 修改岗位的数据范围从"本组织"改为"全部合同"
2. 让用户能看到租户内所有进行中的合同
