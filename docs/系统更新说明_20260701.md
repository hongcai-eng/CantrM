# 系统更新说明

## 更新内容（2026-07-01）

### 1. 租户独立系统配置
每个租户可以独立设置：
- 系统名称
- 公司名称  
- 公司图标

**影响：**
- 一个租户修改配置，不会影响其他租户
- superadmin 的配置独立显示

### 2. 自动数据库升级
`start.bat` 和 `start.sh` 启动脚本已集成自动升级功能。

**使用方法：**
1. 替换旧的 `contracts.db` 到 `instance/` 目录
2. 直接运行 `start.bat`（Windows）或 `start.sh`（Linux）
3. 系统自动检测并升级数据库
4. 升级成功后自动启动应用

**输出示例：**
```
启动合同管理系统...
√ 虚拟环境已激活
正在检查数据库版本...
开始检测数据库...
[OK] system_name 字段已存在
[OK] trial_expires_at 字段已存在
数据库升级完成！

==========================================
合同管理系统 v2.0
==========================================
访问地址：http://localhost:5000
```

## 升级步骤

### 方式一：使用启动脚本（推荐）
```bash
# 1. 备份当前数据库
cp instance/contracts.db instance/contracts.db.backup

# 2. 替换旧数据库
cp /path/to/old/contracts.db instance/contracts.db

# 3. 直接启动（自动升级）
start.bat        # Windows
# 或
./start.sh       # Linux
```

### 方式二：手动升级
```bash
# 1. 备份
cp instance/contracts.db instance/contracts.db.backup

# 2. 替换旧数据库
cp /path/to/old/contracts.db instance/contracts.db

# 3. 手动升级
python upgrade_db.py

# 4. 启动
python app.py
```

## 注意事项
- **务必先备份**数据库再操作
- 升级脚本可以重复运行，不会重复添加字段
- 如升级失败，恢复备份后联系技术支持

## 技术细节
新增数据库字段：
- `tenant_customer.system_name` VARCHAR(200) - 租户系统名称

修改文件：
- `models.py` - 添加字段定义
- `app.py` - 修改配置保存/读取逻辑
- `start.bat` / `start.sh` - 集成自动升级
- `upgrade_db.py` - 数据库升级脚本
