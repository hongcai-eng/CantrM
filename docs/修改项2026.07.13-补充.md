# 修改记录补充 2026.07.13

## 问题描述
用户反馈：付伟龙访问合同列表时，"每页显示"选项位置不符合预期。

原始布局（修改前）：
```
[每页显示：下拉]   [首页|上一页|第X/Y页|下一页|末页]   [跳转到：输入框|GO]
```
三个独立的 flex 容器，gap=20px，分组显示。

期望布局（修改后）：
```
每页显示：下拉 | 首页 | 上一页 | 第X/Y页 | 下一页 | 末页 | 跳转到：输入框 | GO
```
所有元素在同一行，统一 flex 容器，gap=8px，紧凑排列。

## 改动内容

### 涉及文件
- `templates/index.html` - 合同管理首页
- `templates/contract_archive.html` - 合同档案页

### 具体修改
将分页导航从"三段式"改为"一行式"布局：

1. **移除嵌套 div**：删除原有的三个 `<div>` 子容器，所有元素平铺在父容器内
2. **调整间距**：`gap: 20px` → `gap: 8px`，元素更紧凑
3. **增加换行支持**：添加 `flex-wrap: wrap`，窄屏时自动换行
4. **调整"跳转到"间距**：左侧增加 `margin-left: 10px`，与前面分页按钮稍微分隔

### 布局对比

**修改前（三段式）**：
```html
<div style="gap: 20px;">
    <div>每页显示：下拉</div>
    <div>首页 上一页 页码 下一页 末页</div>
    <div>跳转到：输入 GO</div>
</div>
```

**修改后（一行式）**：
```html
<div style="gap: 8px; flex-wrap: wrap;">
    每页显示：下拉
    首页 上一页 页码 下一页 末页
    跳转到：输入 GO
</div>
```

## 兼容性说明

- 布局使用标准 flexbox，兼容所有现代浏览器
- `flex-wrap: wrap` 确保窄屏（如平板、手机）时自动换行，不会横向溢出
- 保持原有 JS 逻辑不变（`changePerPage`、`jumpToPage`、`gotoPage`）
