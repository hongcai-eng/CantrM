## 预防措施

### 1. 文件下载前检查
修改 `app.py` 的 `/download/<filename>` 路由，添加文件存在性检查：

```python
@app.route('/download/<filename>')
@login_required
@permission_required('下载')
def download_file(filename):
    file_path = os.path.join(app.config['UPLOAD_FOLDER'], filename)
    if not os.path.exists(file_path):
        flash('文件不存在或已被删除', 'warning')
        return redirect(request.referrer or url_for('index'))
    return send_file(file_path, as_attachment=True)
```

### 2. 定期检查脚本
建议每周运行一次 `check_missing_files.py` 检查文件完整性。

### 3. 文件备份
重要的上传文件应该定期备份到其他位置。

### 4. 删除文件前检查
如果需要手动清理 `uploads` 目录，应先运行检查脚本确认哪些文件可以安全删除。

## 工具脚本使用

### 检查文件完整性
```bash
python check_missing_files.py
```

### 自动修复缺失的文件引用
```bash
# 交互式修复（每类文件都会询问）
python fix_missing_files.py

# 自动修复（不询问，直接清空所有缺失引用）
python fix_missing_files.py --yes
```

## 数据恢复建议

如果有备份文件，可以：
1. 将备份文件复制到 `uploads` 目录
2. 文件名必须与原始文件名完全一致
3. 然后在系统中重新关联该文件

如果没有备份：
1. 数据库中的合同信息仍然完整
2. 只是附件文件需要重新上传
3. 可以编辑对应的合同记录重新上传文件

## 相关文件

- `check_missing_files.py` - 检查文件完整性
- `fix_missing_files.py` - 修复缺失的文件引用
- `app.py` - 主应用程序（需要添加文件存在性检查）
- `models.py` - 数据模型定义

## 注意事项

⚠️ **运行 `fix_missing_files.py` 会清空数据库中的文件路径记录，这个操作不可逆！**

建议在运行修复脚本前：
1. 备份数据库文件
2. 先运行 `check_missing_files.py` 确认要修复的文件列表
3. 尝试恢复缺失的文件
4. 如果无法恢复，再运行修复脚本
